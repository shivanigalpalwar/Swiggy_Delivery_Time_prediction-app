# Swiggy_Delivery_Time_prediction-app
📌 Project Overview

The Swiggy Delivery Time Prediction project uses Machine Learning to estimate food delivery time based on various factors related to delivery partners, orders, traffic, and environmental conditions.

The application provides a user-friendly interface built with Streamlit, allowing users to enter delivery details and obtain an estimated delivery time in minutes.

🎯 Objectives
Predict estimated food delivery time using a trained Machine Learning model.
Analyze factors that may influence delivery duration.
Provide an interactive and easy-to-use web application.
Demonstrate the practical application of Machine Learning in food delivery services.

🛠️ Technologies Used
Python – Programming language
Pandas – Data manipulation and processing
Scikit-learn – Machine Learning model development
Streamlit – Interactive web application
Pickle – Loading the saved Machine Learning model
